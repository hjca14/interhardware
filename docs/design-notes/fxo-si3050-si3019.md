# FXO Si3050 + Si3019 — implementation record

## Applicable package and source

The implementation uses the **Si3050 TSSOP-16** and **Si3019 SOIC-16/TSSOP-16** pin assignments. The authoritative source is `docs/reference-designs/Si3050-11-18-19.pdf`, in particular Figure 17, “Typical Application Circuit for the Si3050 (TSSOP) and Si3011/18/19 (SOIC/TSSOP)”. QFN pin numbers from the EVB schematic were not transferred to the 16-pin symbols.

The repository also contains AN67, the EVB schematic and its BOM. AN347, a FAQ, and an EVB User Guide are not present in this checkout; their absence did not block the implementation because the applicable TSSOP/SOIC circuit and package information are in the datasheet.

## Isolation and scope

`GND` belongs only to the digital side and `IGND` only to the line side. The two domains have no wire or common net label. C1/C2 are the only intended signal paths across the barrier (`C1A` ↔ `C1B` and `C2A` ↔ `C2B`).

ESP32-C3, USB-C, RJ11 PHONE/pass-through, and a relay are intentionally excluded. The host digital interface, project power-rail choice, and region-specific stuffing/protection choices remain explicit TODOs rather than inferred connections.

## ERC status and warnings

KiCad CLI/Eeschema is unavailable in the execution environment, so graphical loading and ERC could not be run here. A structural parenthesis check, symbol pin-name/number checks, scope checks, and a textual `GND`/`IGND` separation check were run instead. The schematic intentionally contains unconnected host-interface and TODO endpoints until the controller and regional variant are selected; these are expected to produce unconnected-pin warnings when ERC becomes available.
